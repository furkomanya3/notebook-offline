# Notebook Offline

Kendi PDF kaynaklarından **cihazda** cevap veren, **sayfa atıflı**, offline çalışan notebook.
Sunucu yok, hesap yok, API anahtarı yok. PWA + WebGPU (WebLLM) + pdf.js.

## Kullanım

Site: https://furkomanya3.github.io/notebook-offline/
iPhone'da Safari ile aç → Paylaş → **Ana Ekrana Ekle**.

1. Kitaplık → PDF ekle (veya "Demo kaynağı yükle")
2. Model → modeli indir (ilk seferde internet gerekir)
3. Sohbet → soru sor, kaynak atıflarını gör

Veriler yalnızca cihazda (IndexedDB) tutulur; hiçbir soru/cevap sunucuya gitmez.
